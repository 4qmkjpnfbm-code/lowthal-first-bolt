# Lowthal Bot Wars — First Bolt (playable)

Self-contained offline prototype. **No build step.** Open `index.html` in any modern browser, or visit the Cloudflare Pages URL when deployed.

## How to open locally

```bash
python3 -m http.server 8765
# then http://localhost:8765
```

Files: `index.html` · `styles.css` · `game.js`

See `OPS-SMOKE.md` for Door→Folio smoke. Named builds: `BUILDS.md`.

## Design rules

- Soft Glow / ages 7–22
- No auth/DB (potato)
- No Galaxy trademarks in player UI
